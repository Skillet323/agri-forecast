# Эксперименты

Три ноутбука, каждый проверяет свой вопрос на реальных открытых данных.
Основной проект отвечает на них не так тщательно, как хотелось бы, поэтому
разбор вынесен сюда отдельно.

## 01_feature_sets.ipynb — какой набор признаков вообще нужен

В основном проекте расширение признаков (температура и осадки → плюс радиация
и влажность) не улучшает прогноз на годовых данных, а немного ухудшает.
Здесь этот результат проверяется тщательнее: перебор шести наборов признаков,
доверительные интервалы через бутстреп, сравнение с моделью, которая просто
предсказывает среднее по обучению, и отдельно — сколько от качества прогноза
на самом деле даёт не погода, а тренд последних двадцати лет.

## 02_cross_country.ipynb — переносится ли вывод на другие страны

Та же методика — урожайность из World Bank, погода из NASA POWER, одна
точка на страну — прогоняется на пяти зерновых странах (Россия, Украина,
Казахстан, Франция, Аргентина). Проверяется, одинаково ли ведёт себя модель
и одинаковый ли знак у эффекта расширения признаков, или вывод, полученный
на одной стране, брать за общее правило нельзя.

## 03_kaggle_and_agro_econ.ipynb — что ещё может объяснять урожайность

Две части. Первая — агроэкономические показатели того же World Bank:
внесение удобрений, доля орошаемых земель, доля сельского хозяйства в ВВП.
Сравнивается, что лучше объясняет рост урожайности за двадцать лет — погода
или экономика (спойлер: агротехника обычно объясняет больше, и это стоит
держать в голове при интерпретации любой модели на одной только погоде).

Вторая часть — подключение датасета с Kaggle. Работает только с ключами API,
без них ноутбук честно об этом пишет и пропускает эту часть, не ломая
остальное.

## Про сеть

Все три ноутбука делают настоящие запросы к открытым API — NASA POWER,
World Bank, при желании Kaggle. Ключи нужны только для последнего. Если
какой-то запрос не проходит:

- `ConnectionError`, `Timeout` — обычно временная проблема сети, стоит
  повторить через минуту;
- пустой ответ от World Bank по показателю — значит, для этой страны и этих
  лет он не публиковался, нужно проверить код показателя на data.worldbank.org;
- Kaggle без ключей — `RuntimeError` с понятным текстом, а не невнятная
  ошибка авторизации где-то в глубине `requests`.

## Зависимости

Всё, что нужно, уже в `requirements.txt` корня проекта (`pip install -r ../requirements.txt`).
Дополнительно нужен `scipy` — для линии тренда во
втором ноутбуке, но он тоже уже в общем requirements.
